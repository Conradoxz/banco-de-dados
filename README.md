# 🗄️ Banco de Dados

Este repositório foi criado para armazenar atividades, exercícios, projetos e conteúdos desenvolvidos durante as aulas da disciplina de **Banco de Dados**.

## 📚 Sobre a disciplina

A matéria de Banco de Dados tem como objetivo ensinar como **armazenar, organizar, relacionar e consultar informações** de forma eficiente utilizando sistemas de gerenciamento de banco de dados.

Durante as aulas, serão estudados conceitos teóricos e práticos relacionados à criação e manutenção de bancos de dados.

## 📖 Conteúdos estudados

* Conceitos básicos de Banco de Dados
* SGBD (Sistema Gerenciador de Banco de Dados)
* Modelo Entidade-Relacionamento (MER)
* Diagrama Entidade-Relacionamento (DER)
* Entidades, atributos e relacionamentos
* Chaves primárias e estrangeiras
* Cardinalidade
* Normalização de dados
* Modelo relacional
* Criação de tabelas
* Linguagem SQL
* Comandos `CREATE`, `INSERT`, `UPDATE` e `DELETE`
* Consultas utilizando `SELECT`
* Relacionamento entre tabelas

## 💻 Tecnologias

Algumas das tecnologias e ferramentas utilizadas durante a disciplina:

* SQL
* MySQL
* MySQL Workbench
* Banco de Dados Relacional
